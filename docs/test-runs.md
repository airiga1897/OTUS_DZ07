## Локальная проверка управления

Из корня проекта в PowerShell:

```powershell
.\.tools\venv\Scripts\python.exe -m unittest discover -s tests -v
```

Проверяются сохранение работающего стенда при успехе, повторная проверка
приложения после восстановления, очистка при ошибке даже при недоступной
диагностике и отсутствие облачных изменений при ошибке подготовки.
Эти проверки используют подставной адаптер и не подтверждают работу облачных сервисов.

Публичная команда `deploy` дополнительно проверена с настоящими API и Terraform:
при отказе выделения физических хостов она вернула ненулевой код и удалила
частично созданный стенд. Отдельная команда `destroy` подтвердила отсутствие
ресурсов. Этот контроль не подтверждает повторную успешную приёмку `verify`;
для неё требуется доступная ёмкость облака. Сохранённые выше результаты полной
приёмки и контроль аварийной очистки относятся к разным проверкам.
Отдельный запуск `verify` на пустом state вернул ненулевой код; отсутствие
стенда не было принято за успешную проверку. Повторный `destroy` также завершился
успешно. [Сводка проверки команд](command-checks.json).

Ссылки на файлы и синтаксис PowerShell проверяются локально. Визуальное
отображение обновлённой документации в GitHub не подтверждено: подключение
управляемого браузера недоступно. Проверка Markdown не заменяет эту проверку.
