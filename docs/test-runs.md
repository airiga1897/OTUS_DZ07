## Локальная проверка управления

Из корня проекта в PowerShell:

```powershell
.\.tools\venv\Scripts\python.exe -m unittest discover -s tests -v
```

Проверяются сохранение работающего стенда при успехе, повторная проверка
приложения после восстановления, очистка при ошибке даже при недоступной
диагностике и отсутствие облачных изменений при ошибке подготовки.
Эти проверки используют подставной адаптер и не подтверждают работу облачных сервисов.
