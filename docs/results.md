# Результаты проверки ДЗ07

## Текущие исходники

Полный test-cycle выполнен на незакоммиченном рабочем дереве: четыре ВМ
в ru-2, без es4, выключения узлов и Глобального роутера. Исходники и проверенные
пакеты передавались по SSH в явно выбранном режиме `cached`; после удаления
восстановлен `release`. Публикация не выполнялась.

| Проверка | Ожидаемое поведение | Подтверждено |
| --- | --- | --- |
| Elasticsearch | Три узла с репликой индексов и разнесением по хостам | `green`, три data/master-узла, три физических хоста, нет неназначенных шардов |
| Сайт | HTTP-запросы через HAProxy, Nginx и Django; доступна статья ДЗ07 | Главная страница и статья — HTTP 200; чтение и запись через приложение прошли |
| Источники логов | События каждой службы на соответствующей ВМ | Все 12 сочетаний узел/источник, семь видов журналов, 20 860 событий в снимке проверки |
| Kibana | Доступность и представление данных | HTTP 200, `available`, представление и дешборд `otus-logs` |
| Повторный deploy | Сохранение ресурсов и пользовательских данных | ID, документы ES, записи БД и media сохранены; начальная фикстура повторно не загружалась |
| Ansible | Независимая systemd-операция, ход задач без раскрытия no_log | Первый и повторный запуск завершились с кодом 0; события задач получены |
| Удаление | Собственные ресурсы отсутствуют в state и API | Остаток 0 в сохранённой области ru-2; контекст, state и ключи удалены; реквизиты сохранены |

## Локальные проверки

[Полный локальный набор](local-quality.md) подтвердил 1617 тестов, Ruff,
mypy для win32/linux и pre-commit. Измерено 9130/9130 строк и 3032/3032 ветвей.
Внешние операции подставляются, данные создаются во временных каталогах.
Процент покрытия не доказывает полноту сценариев и работу облачного API.

## Доставка опубликованного выпуска

[Чистый клон опубликованной версии](release-public-verification.json) и
[её облачный прогон](release-cloud-acceptance.json) подтверждают GitHub Releases
без S3. Эти результаты относятся к закреплённому выпуску, а не к последующим
локальным изменениям. Текущий облачный цикл с `cached` не подтверждает доставку
нового кода через прежний Release. [Требования к согласованной версии](releases.md).

## Границы подтверждения

Переход между пулами с условным созданием Глобального роутера, прерывание
подключений и обрыв SSH покрыты локальными сценариями. В текущем облачном цикле
все ВМ находились в одном пуле; намеренные отказы и es4 не испытывались.
Примеры журналов не являются доказательством отсутствия потерь при любой аварии.
