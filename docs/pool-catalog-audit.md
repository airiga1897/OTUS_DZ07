# Проверка причин исключения пулов

Каталоги, возможности, квоты и группы зон Selectel прочитаны через API
31 октября 2026 года. Выполнялись только авторизация и запросы чтения;
новые ВМ и сети не создавались, действующий ручной стенд не изменялся.
[Обезличенный результат](pool-catalog-audit.json).

| Пул или сегмент | Подтверждённая причина и результат |
| --- | --- |
| ru-4, ru-5 | Точный образ `Ubuntu 24.04 LTS 64-bit` не найден; пулы явно исключены из размещения ВМ. Также не найден публичный HTTPS endpoint `volumev3` |
| ru-2 | Публичная активная сборка `Ubuntu 24.04 LTS 64-bit` от 14.04.2026 включена в явный список разрешённых MD5; работа ролей подтверждена [полным test-cycle в ru-2a](ru2-test-cycle-summary.json) |
| ru-6a/b/c | В каталоге есть `universal2.*`, но нет типов с подтверждённой привязкой, разрешённых масками `universal.*` и `basicssd.*` |
| ru-1a | Каталоговое сочетание есть, но квота `compute.ram` равна нулю |
| ru-1b | Разрешённые типы дисков привязаны к ru-1a и ru-1c, а не к ru-1b |
| ru-1c | Исправлена ошибка сопоставления: ВМ и диск в ru-1c могут использовать общий сетевой домен ru-1a, объявленный API |
| ru-3a, ru-3b, ru-8a, ru-9a | Найдены каталоговые сочетания с разрешёнными образами, дисками и конфигурациями ВМ |

Ошибка была в приравнивании вычислительного сегмента к имени сетевого домена.
Selectel обеспечивает L2-связность между сегментами пула, а сетевая
инфраструктура работает на уровне пула или зоны доступности.
[Документация Selectel](https://docs.selectel.ru/infrastructure/locations/).
Исправленный адаптер использует точный домен API либо единственный обычный
домен того же пула. Неоднозначные варианты, чужие пулы и служебные `*-paas`
не выбираются автоматически. Явные соответствия сохраняют приоритет.

Для ru-6 сопоставление общей сети и зон маршрутизатора исправлено, но
ограничение типов дисков сохраняется; пул исключён в `.env.example`.
Сегмент ru-1b исключён через `SELECTEL_EXCLUDED_SEGMENTS`. Новый класс `universal2.*` не добавлялся.
Параметры ВМ, разнесение ES и ранее действовавшие исключения сохраняются.
Разрешённые значения Glance `checksum` (MD5) хранятся только в
[`config/placement.json`](../config/placement.json), поле `image_checksums`.
Допуск любой из двух сумм не отменяет проверки точного названия, публичности,
состояния `active`, `os_distro=ubuntu`, архитектуры, `min_disk` и `min_ram`.
Размещение уже созданных ресурсов не пересчитывается.

Повторное чтение каталогов исправленным кодом подтвердило варианты
ru-1a, ru-1c, ru-3a, ru-3b, ru-8a и ru-9a. Полная предварительная проверка
дополнительно учитывает квоты, в том числе нулевую RAM ru-1a. Каталоги и
положительные квоты не подтверждают наличие физических хостов; создание
ресурсов этим аудитом не проверялось.
