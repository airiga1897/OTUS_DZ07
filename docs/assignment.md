# Домашнее задание

Настройка централизованного сбора логов в кластер Elasticsearch

**Цель:**

- развернуть отказоустойчивый кластер Elasticsearch;
- централизованно собирать логи с серверов проекта;
- обеспечить визуализацию логов для мониторинга и диагностики.

**Описание/Пошаговая инструкция выполнения домашнего задания:**

*Централизованный сбор логов позволяет быстро выявлять ошибки и сбои в распределённых системах. Elasticsearch обеспечивает масштабируемое хранилище для логов, а визуализация помогает команде DevOps и разработчикам принимать решения на основе реальных данных.*

1. Разверните кластер Elasticsearch из минимум трёх узлов.

   - Обеспечьте корректную настройку параметров discovery.seed_hosts, cluster.initial_master_nodes и сетевого взаимодействия между узлами.

2. Выберите и настройте инструмент сбора логов (например, Filebeat или Logstash).

   - Установите его на веб-серверы, базы данных и балансировщики.
   - Настройте отправку логов в Elasticsearch.

3. Настройте шаблоны индексов и правила для обработки логов.
4. Проверьте, что логи успешно поступают в Elasticsearch и отображаются.
5. (Опционально) Подключите Kibana для визуализации логов и настройки дешбордов.

**Формат сдачи**

- Скрипты/манифесты для развертывания Elasticsearch и системы сбора логов
- Примеры логов, отображающихся в кластере
- README.md с кратким описанием архитектуры и шагов развёртывания
