Основная инструкция — [README проекта](../README.md). Для обычной эксплуатации:
подготовка → реквизиты → deploy → verify → open → отдельный destroy.

JSON-отчёты, на которые ссылается [таблица результатов](results.md), содержат
обезличенные доказательства. Они не являются служебными файлами восстановления.
State, контекст, ключи и реквизиты находятся локально и в документацию не входят.
