## 2. Находки

P1 нет.

Три ранее подтверждённых дефекта остаются закрытыми: неизвестная привязка диска не скрывает следующие типы, некорректный `availability_zones` не прерывает остальные flavor, резерв портов считается одним помощником. Регрессии из `scripts/test_cursor_review_regressions.py` проходят.

### P2. Неподтверждённый диск flavor принимался как сетевая загрузка

Файл: `scripts/pool_selection.py`, строка 161, `flavor_choices`.

Воспроизведение: flavor с именем и размерами SL1/SL2, но без поля `disk`, либо с `disk` равным `False` или `0.0`. До исправления `item.get('disk', 0) == 0` считал такой ответ сетевой загрузкой. Подтверждённый flavor с целым `disk == 0`, стоящий следом, не был единственным кандидатом: непроверенный тоже попадал в список.

Следствие: каталог без обязательного целого поля `disk` мог выбрать конфигурацию, которая не подтверждена как сетевой загрузочный диск.

Исправлено. Нужен `type(disk) is int` и значение `0`. Отсутствие поля, `False`, `0.0` и прочие типы пропускаются; если подтверждённых flavor не осталось, роль отклоняется. Регрессия: `scripts/test_cursor_full_review.py`, `UnconfirmedCatalogTests`.

### P2. Одна страница коллекции OpenStack считалась полной

Файлы: `scripts/selectel_adapter.py`, `collection` (строка 156), `audit_cleanup` (строка 162), `reject_cloud_resources` (строка 365); `scripts/selectel_staged.py`, проверка floating IP при `audit_deletion` (строка 579).

Воспроизведение: первая страница `/servers/detail` содержит чужое имя и ссылку `next`, вторая — `otus-dz07-app`. Первая страница floating IP пуста, вторая содержит собственный ID. Отдельно первая страница из 200 объектов без ссылки `next` не подтверждает полноту. До исправления `audit_cleanup` и `reject_cloud_resources` читали путь один раз и обходили любые списки в ответе. `audit_deletion` так же читал `/v2.0/floatingips` без продолжения страниц. Проверка возвращала пустой остаток и нулевое число адресов.

Следствие: destroy мог сообщить, что именованные ресурсы удалены, а test-cycle — что проект пуст, хотя следующая страница ещё содержала собственные ВМ или floating IP.

Исправлено. Чтение идёт через уже существующий `objects()`: учитывается `next`, посторонний URL отклоняется, страница из 200 записей без `next` не считается полной. Регрессия: `CollectionCompletenessTests` в том же файле. Фикстуры соседних тестов переведены на ключи коллекций API, чтобы больше не принимать произвольный список в ответе за полный каталог.

### Не исправлялось

Поле `os-flavor-access:is_public` по-прежнему считается истинным, если ключ отсутствует: для списка flavor это необязательное расширение, а не обязательное поле Nova. Отсутствие верхнеуровневого `architecture` у образа по-прежнему трактуется как `x86_64`; в ответах Glance архитектура часто лежит в properties, и отказ по отсутствию поля мог бы отбросить пригодные образы без подтверждённого контракта. Проверка `server_group_members` сравнивает лимит группы с 3, а не свободный остаток: для Nova это максимум группы. Окно refresh только для `attachment` не расширялось: фактические поля прошлого облачного plan не сохранены. Устаревший `terraform-selectel/main.tf` по-прежнему задаёт `scheduler_hints` и не является путём нового поэтапного deploy.
